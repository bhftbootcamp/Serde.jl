Serde.jl

Serde is a Julia library for (de)serializing data to/from various formats. The library offers a simple and concise API for defining custom (de)serialization behavior for user-defined types. Inspired by the serde.rs Rust library, it supports the following data formats:

Installation

To install Serde, simply use the Julia package manager:

] add Serde

Usage

Let's look at some of the most common use cases.

Deserialization

The following example shows how to deserialize market trade data from various formats into a custom structure Trade. The deserialization of the timestamp field is customized by adding a method for Serde.deser that converts Unix milliseconds to a DateTime.

using Dates, Serde

struct Trade
    symbol::String
    price::Float64
    quantity::Float64
    side::String
    timestamp::DateTime
end

function Serde.deser(::Type{Trade}, ::Type{DateTime}, v::Integer)
    return Dates.unix2datetime(v / 1000)
end

# JSON deserialization
json = """
{
  "symbol": "BTCUSDT",
  "price": 67420.5,
  "quantity": 0.015,
  "side": "buy",
  "timestamp": 1720000000000
}
"""

julia> trade = from_json(Trade, json)
Trade("BTCUSDT", 67420.5, 0.015, "buy", DateTime("2024-07-03T06:13:20"))

# TOML deserialization
toml = """
symbol    = "BTCUSDT"
price     = 67420.5
quantity  = 0.015
side      = "buy"
timestamp = 1720000000000
"""

julia> trade = from_toml(Trade, toml)
Trade("BTCUSDT", 67420.5, 0.015, "buy", DateTime("2024-07-03T06:13:20"))

# URL query string deserialization
query = "symbol=BTCUSDT&price=67420.5&quantity=0.015&side=buy&timestamp=1720000000000"

julia> trade = from_query(Trade, query)
Trade("BTCUSDT", 67420.5, 0.015, "buy", DateTime("2024-07-03T06:13:20"))

# CSV deserialization
csv = """
symbol,price,quantity,side,timestamp
BTCUSDT,67420.5,0.015,buy,1720000000000
ETHUSDT,3512.0,1.2,sell,1720000001000
"""

julia> trades = from_csv(Trade, csv)
2-element Vector{Trade}:
 Trade("BTCUSDT", 67420.5, 0.015, "buy", DateTime("2024-07-03T06:13:20"))
 Trade("ETHUSDT", 3512.0, 1.2, "sell", DateTime("2024-07-03T06:13:21"))

# YAML deserialization
yaml = """
symbol: BTCUSDT
price: 67420.5
quantity: 0.015
side: buy
timestamp: 1720000000000
"""

julia> trade = from_yaml(Trade, yaml)
Trade("BTCUSDT", 67420.5, 0.015, "buy", DateTime("2024-07-03T06:13:20"))

# XML deserialization
xml = """
<trade symbol="BTCUSDT" price="67420.5" quantity="0.015" side="buy" timestamp="1720000000000" />
"""

julia> trade = from_xml(Trade, xml)
Trade("BTCUSDT", 67420.5, 0.015, "buy", DateTime("2024-07-03T06:13:20"))

If you want to see more deserialization options, take a look at the corresponding section of the documentation.

Serialization

The following example shows how an object trade of type Trade can be serialized into various formats. The timestamp field is converted back to Unix milliseconds by overloading ser_type.

using Dates, Serde

struct Trade
    symbol::String
    price::Float64
    quantity::Float64
    side::String
    timestamp::DateTime
end

trade = Trade("BTCUSDT", 67420.5, 0.015, "buy", DateTime("2024-07-03T06:13:20"))

# JSON serialization
function Serde.ser_type(::Type{Trade}, v::DateTime)
    return round(Int, Dates.datetime2unix(v) * 1000)
end

julia> to_json(trade) |> print
{"symbol":"BTCUSDT","price":67420.5,"quantity":0.015,"side":"buy","timestamp":1720000000000}

# TOML serialization
julia> to_toml(trade) |> print
symbol    = "BTCUSDT"
price     = 67420.5
quantity  = 0.015
side      = "buy"
timestamp = 1720000000000

# CSV serialization
julia> to_csv([trade]) |> print
symbol,price,quantity,side,timestamp
BTCUSDT,67420.5,0.015,buy,1720000000000

If you want to see more serialization options, take a look at the corresponding section of the documentation.

Strategies

Pass a strategy as the first argument to rename fields automatically across all formats. Use With to compose multiple strategies into one:

using Serde

struct Order
    order_id::String
    asset_symbol::String
    notional_usd::Float64
end

# API sends camelCase — CamelCase() maps camelCase keys to snake_case fields
julia> from_json(CamelCase(), Order, """{"orderId":"abc","assetSymbol":"BTC","notionalUsd":50000.0}""")
Order("abc", "BTC", 50000.0)

# Serialize back with camelCase keys
julia> to_json(CamelCase(), Order("abc", "BTC", 50000.0)) |> print
{"orderId":"abc","assetSymbol":"BTC","notionalUsd":50000.0}

See Strategies for the full list of built-in strategies and the With composer.
