Serde.jl

Serde is a Julia library for serializing and deserializing data in multiple formats. Inspired by serde.rs, it provides a unified API across all supported formats with fine-grained customisation through a small set of trait functions.

Usage

Deserialization

Suppose you receive market trade data from a REST API as JSON with camelCase field names, but your internal type uses snake_case. Pass CamelCase() as a strategy and Serde handles the renaming automatically:

using Serde

struct Trade
    symbol::String
    price::Float64
    quantity::Float64
    side::String
end

# JSON from exchange API uses camelCase
json = """
[
  {"symbol":"BTCUSDT","price":67420.5,"quantity":0.15,"side":"buy"},
  {"symbol":"ETHUSDT","price":3512.0,"quantity":1.2,"side":"sell"}
]
"""

trades = from_json(CamelCase(), Vector{Trade}, json)
# 2-element Vector{Trade}:
#  Trade("BTCUSDT", 67420.5, 0.15, "buy")
#  Trade("ETHUSDT", 3512.0, 1.2, "sell")

The same type works with any supported format — no extra code needed:

# CSV batch export
csv = """
symbol,price,quantity,side
BTCUSDT,67420.5,0.15,buy
ETHUSDT,3512.0,1.2,sell
"""
trades = from_csv(Trade, csv)

# YAML config file
yaml = """
- symbol: BTCUSDT
  price: 67420.5
  quantity: 0.15
  side: buy
"""
trades = from_yaml(Vector{Trade}, yaml)

For more deserialization options see the Extended deserialization section.

Serialization

Serialize your types to any format with a matching to_* function. Use strategies to control field naming in the output:

using Serde

struct OrderBook
    symbol::String
    best_bid::Float64
    best_ask::Float64
    spread::Float64
end

book = OrderBook("BTCUSDT", 67418.0, 67422.0, 4.0)

# Compact JSON (snake_case keys — default)
to_json(book)
# {"symbol":"BTCUSDT","best_bid":67418.0,"best_ask":67422.0,"spread":4.0}

# Pretty JSON with camelCase keys (e.g. for a REST response)
to_pretty_json(CamelCase(), book)
# {
#   "symbol": "BTCUSDT",
#   "bestBid": 67418.0,
#   "bestAsk": 67422.0,
#   "spread": 4.0
# }

# TOML for a human-readable snapshot file
to_toml(book)

For more serialization options see the Extended serialization section.

Custom type conversion

Override Serde.deser for precise control over how individual values are converted:

using Dates, Serde

struct Candle
    symbol::String
    open_time::DateTime
    open::Float64
    high::Float64
    low::Float64
    close::Float64
end

# Exchange timestamps arrive as Unix milliseconds
function Serde.deser(::Type{Candle}, ::Type{DateTime}, ms::Integer)
    return Dates.unix2datetime(ms / 1000)
end

json = """{"symbol":"BTCUSDT","open_time":1720000000000,
           "open":67000.0,"high":68000.0,"low":66500.0,"close":67800.0}"""

candle = from_json(Candle, json)
# Candle("BTCUSDT", DateTime("2024-07-03T06:13:20"), 67000.0, 68000.0, 66500.0, 67800.0)

Strategies

Use With to compose multiple strategies in a single call:

using Serde

struct Position
    asset_id::String
    notional_usd::Float64
    is_hedged::Bool
end

# API sends camelCase; skip null/zero fields when serialising back
w = With(CamelCase())
pos = from_json(w, Position, """{"assetId":"BTC","notionalUsd":500000.0,"isHedged":true}""")
to_json(w, pos)
# {"assetId":"BTC","notionalUsd":500000.0,"isHedged":true}

See Strategies for the full list of built-in strategies.
